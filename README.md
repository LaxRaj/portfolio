# Portfolio

Personal site and design portfolio, built with Next.js, TypeScript, and Tailwind CSS.

Currently a blank canvas — `src/app/page.tsx` is intentionally empty, ready for a fresh design.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Real content already lives in `src/data/` — no component code needed to use it:

- `src/data/profile.ts` — name, bio, socials, skills, life/off-work notes
- `src/data/projects.ts` — CrossCode, Signal, Atlas, and other project entries
- `src/data/resume.ts` — experience, education, skills, leadership

Also available:

- `public/resume.pdf` — real downloadable resume
- `public/og-image.png` — social share image

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS v4

## Deploy

```bash
vercel deploy
```
